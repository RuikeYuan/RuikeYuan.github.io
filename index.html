Bachelor's Thesis · Leiden University Grade 8.5

AI-driven Smart UI Generation from UML Models

A working prototype that integrates LLMs into Model-Driven Engineering. Instead of asking an LLM to generate an interface from scratch, UML models are first turned into structured interface metadata, refined by an LLM, and compiled into a runnable web app — keeping AI output grounded in the software design.

UML models→Interface metadata→LLM refinement→UI spec→Web prototype
  • LLMs
  • Model-Driven Eng.
  • UML
  • Web
  • Human-in-the-loop

Exoplanet Atmosphere Retrieval

Applied ML 2026

PartVision

Recognises car parts from a photo and routes each one to auto-accept, confirm-from-top-3, manual or unknown. Combines a ResNet classifier with a cosine kNN index for open-set detection; every human confirmation becomes training data, and a retrained model is promoted only if it beats the current one on a fixed holdout.

  • v001 93.6% holdout top-1
  • v002 94.2% after feedback retrain
  • PyTorch
  • ResNet
